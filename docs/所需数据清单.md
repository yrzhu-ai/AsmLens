# AsmLens 服务器端 — 你需要准备的数据

按优先级：有 **A** 就能跑通主流程；**B/C** 越全，结论越完整。

## A. 必做（双基因组低覆盖对比）

| 数据 | 说明 | 参数 |
|---|---|---|
| 自己的组装基因组 | FASTA | `-q` |
| 参考 / T2T / 他人组装 | FASTA（可选但强烈建议） | `-ref` |
| 至少一种测序数据 | HiFi / CLR / ONT / Illumina | `-hifi` / `-clr` / `-ont` / `-Illumina` |
| 线程数 | | `-t` |

示例（你现在的 test1 已具备 A）：

```bash
asmlens run \
  -q example.fa \
  -ref aft.fa \
  -hifi example_HiFi.fastq.gz \
  -t 16 \
  -o asmlens_out
```

## B. 多套测序（推荐）

同一套材料的多技术 reads，**都比对到 -q 和 -ref**，桌面可叠多条覆盖轨：

| 类型 | 文件 | 参数 |
|---|---|---|
| PacBio HiFi | `*.fq.gz` | `-hifi` |
| PacBio CLR | `*.fq.gz` | `-clr` |
| ONT | `*.fq.gz` | `-ont` |
| Illumina | R1/R2 或 interleaved | `-Illumina` |

可同时给多种，例如：

```bash
asmlens run -q asm.fa -ref ref.fa \
  -hifi hifi.fq.gz -clr clr.fq.gz -ont ont.fq.gz \
  -Illumina illumina_R1.fq.gz illumina_R2.fq.gz \
  -t 32 -o out
```

## C. 质控插件输入（有则接入）

| 数据 | 说明 | 参数 |
|---|---|---|
| CRAQ 结果目录 | 含 `runAQI_out/`（CRE/CSE/… bed） | `--craq-dir` |
| Merqury / 窗口 QV | 低 QV 的 BED，或 chrom/start/end/QV 表 | `--qv-bed` / `--qv-tsv` |
| SyRI | 需本机有 `syri`；且 `--align-mode nucmer --run-syri` | 可选 |

CRAQ/QV **不需要再提供 BAM 给桌面**；服务器读完坐标写入交付包即可。

## D. 以后单碱基深挖（暂不进交付包）

| 数据 | 用途 |
|---|---|
| 问题区局部 BAM 切片 | 放大到碱基时用（第二期） |
| 全基因组 BAM | 只留服务器，不打包 |

## 不需要（桌面交付）

- 全量 BAM/CRAM  
- 原始 depth 全文  
- 原始 fastq  

交付物只有：`asmlens_bundle_*.zip`（BED / bedGraph / 映射表 / summary）。

## 染色体命名注意

`-q` 与 `-ref` 的染色体 ID 尽量规范、可对应（或保证共线性比对能配对）。  
若一边是 `Chr01`、一边是 `v1chr01`，只要 minimap2/nucmer 能比上即可，归因表会带双方坐标。
